# 🚀 Space Dodge

A simple **Space Dodge game** made with Python using the **Pygame** library.

This is my first project using Pygame. The goal of the game is to control the player and dodge the falling stars for as long as possible.

## 🎮 How to Play

* Use the **Left Arrow (←)** key to move left.
* Use the **Right Arrow (→)** key to move right.
* Avoid the falling stars.
* The game tracks how long you survive.
* If a star hits the player, the game ends.

## 🛠️ Built With

* **Python**
* **Pygame 2.6.1**

## 📦 Installation

Make sure Python is installed on your computer.

Install Pygame with:

```bash
pip install pygame
```

If `pip` doesn't work, try:

```bash
python3 -m pip install pygame
```

## ▶️ Run the Game

Clone or download this repository, then open the project folder in your terminal.

Run:

```bash
python3 main.py
```
